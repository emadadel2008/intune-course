# Microsoft Intune Endpoint Administrator – Arabic Course

كورس عملي باللغة العربية لإدارة الأجهزة باستخدام **Microsoft Intune / Microsoft Endpoint Manager**  
يشمل شرح نظري + تطبيق عملي + مشروع تطبيقي نهائي (Capstone).

---

## 🎯 أهداف الكورس

- فهم دور Microsoft Intune في إدارة الأجهزة الحديثة
- إعداد بيئة Intune من الصفر
- إدارة تسجيل الأجهزة (Enrollment) والسياسات
- تطبيق سياسات الأمان والامتثال
- نشر التطبيقات وإدارتها
- تحليل التقارير واتخاذ قرارات مبنية على البيانات
- تنفيذ سيناريو حقيقي مشابه لبيئات الشركات

---

## 🧠 الفئة المستهدفة

- مهندسو IT و Helpdesk
- System / Cloud / Security Engineers
- أي شخص يريد التخصص في Endpoint Management
- المتقدمون لشهادة **MD-102**

---

## 🛠 المتطلبات

- اشتراك Microsoft 365 (Business Premium أو E5 Trial)
- صلاحيات Global Admin أو Intune Admin
- جهاز Windows 11
- جهاز Android أو Emulator
- معرفة أساسية بـ Microsoft 365 و Entra ID

---

## 📚 محتوى الكورس

### Module 01 – Introduction
التعريف بالكورس، أهمية Intune، ونموذج الإدارة الحديثة.

### Module 02 – Intune Fundamentals
فهم الفرق بين Intune و Configuration Manager ومكونات المنصة.

### Module 03 – Getting Started
إعداد Tenant، المستخدمين، المجموعات، والتكامل مع Entra ID.

### Module 04 – Device Enrollment & Management
تسجيل وإدارة أجهزة Windows، Android، iOS، macOS.

### Module 05 – Application Management
نشر التطبيقات وإدارة التحديثات وحماية التطبيقات (MAM).

### Module 06 – Security & Compliance
Conditional Access، Endpoint Security، Defender Integration.

### Module 07 – Remote Help & Support
الدعم الفني عن بعد و Troubleshooting.

### Module 08 – Reporting & Analytics
تقارير Intune و Endpoint Analytics.

### Module 09 – Integrations & Automation
Autopilot، Purview، PowerShell، Microsoft Graph.

### Module 10 – Best Practices & Real-World Scenarios
أفضل الممارسات والأخطاء الشائعة.

### Module 11 – Capstone Project
مشروع عملي شامل يحاكي بيئة شركة حقيقية.
